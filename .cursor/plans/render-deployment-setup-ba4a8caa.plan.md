# Render Deployment Plan

## Render Requirements

### 1. Web Service Configuration

- **Service Type**: Web Service
- **Build Command**: `pip install -r requirements.txt`
- **Start Command**: `uvicorn app.api.main:app --host 0.0.0.0 --port $PORT`
- **Python Version**: 3.7+ (specify in `runtime.txt` or `requirements.txt`)
- **Environment**: Python 3

### 2. Database Service

- **Service Type**: PostgreSQL (Render PostgreSQL supports TimescaleDB extensions)
- **Database Name**: Will be auto-generated by Render
- **Connection**: Render provides `DATABASE_URL` environment variable
- **Note**: May need to enable TimescaleDB extension manually or use Render's PostgreSQL with TimescaleDB support

### 3. Environment Variables (Required in Render Dashboard)

- `GEMINI_API_KEY` - Your Gemini API key
- `TIMESCALE_SERVICE_URL` - Database connection string (from Render PostgreSQL service)
- `PORT` - Automatically set by Render (don't set manually)

### 4. Static Files

- Render will serve static files through FastAPI's StaticFiles middleware
- No additional configuration needed

## Code Changes Required

### 1. Create `render.yaml` (Optional but Recommended)

- Define web service and database service
- Set build and start commands
- Configure environment variables

### 2. Update Port Configuration

- Modify `run_server.py` to use `PORT` environment variable (Render requirement)
- Update `app/api/main.py` if it has hardcoded port
- Default to port 8000 if `PORT` not set (for local development)

### 3. Create `runtime.txt` (Optional)

- Specify Python version (e.g., `python-3.11`)

### 4. Update Database Connection

- Ensure `TIMESCALE_SERVICE_URL` can use Render's `DATABASE_URL` format
- May need to map `DATABASE_URL` to `TIMESCALE_SERVICE_URL` if Render provides different variable name

### 5. Create `.env.example` (Documentation)

- Template for required environment variables
- Helps with local development setup

## Files to Create/Modify

1. **render.yaml** - Render service configuration
2. **runtime.txt** - Python version specification
3. **run_server.py** - Update to use PORT env var
4. **.env.example** - Environment variable template
5. **README.md** - Add deployment section (optional)

## Important Notes

- Render's PostgreSQL may need TimescaleDB extension enabled (check if available)
- Static files path may need adjustment for production
- CORS settings in `app/api/main.py` should be restricted in production
- Database migrations/initialization may need to run on first deploy
